# 💰 Expense Tracker

A full-stack web application designed to simplify personal finance management by tracking income, expenses, categories and overall savings.

## 📌 Project Overview

The Expense Tracker allows users to record and manage their financial transactions through an interactive dashboard. It provides summaries of income and expenses, maintains transaction history and stores records persistently in a database.

## ✨ Key Features

- **Transaction Management:** Add and delete income and expense records.
- **Category Management:** Organize transactions into different categories.
- **Dashboard:** View total income, total expenses and current net savings.
- **Transaction History:** Access recorded transactions with category labels.
- **Input Validation:** Validate user inputs on both frontend and backend.
- **Persistent Storage:** Store transaction records using SQLite.
- **Responsive Design:** Support desktop and mobile screens.
